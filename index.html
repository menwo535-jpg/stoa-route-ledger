Query and valuation methodology

Each row is one Routed event keyed by transaction hash and log index. Trader wallets count distinct nonzero output recipients. A route may touch several venues. Current and legacy Uniswap v4 adapters share one venue name.

USDG is valued at $1. Other swaps use the router’s ETH/USDG mark or a token-to-USDG quote at the displayed block. These estimates can change on refresh. Swaps without a quote still count and are excluded from volume. Date windows end at the snapshot timestamp.
